# Как находить «начинающих, которые проговорились» про бессмертие

Практический плейбук + рабочий инструмент [`src/Scraping`](src/Scraping/README.md) (F#, .NET 10).

---

## 1. В чём настоящая сложность

Вам нужен не поиск по названиям, а поиск **по произнесённому тексту**. Блогер, который «не решил, о чём говорить», не поставит «бессмертие» в заголовок — он скажет это на 12-й минуте видео про продуктивность.

Отсюда три вывода:

1. **Поиск по заголовкам бесполезен** — он находит только тех, кто уже сделал бессмертие темой (это не ваша аудитория).
2. **Нужен поиск по субтитрам.** YouTube индексирует авто-субтитры, поэтому запрос `бессмертие` находит и те видео, где слово только *сказано*. Это главный механизм.
3. **Нужен фильтр «случайности».** Признак «проговорился» — тема канала НЕ про бессмертие, а упоминание есть. Формально: `seedHits >= 1` при `hitRatio <= 20 %`.

## 2. Четыре сигнала «это он»

| Сигнал | Как измерять | Порог |
|---|---|---|
| **Размер** | подписчики / число видео | ≤ 5 000 подписчиков, ≤ 120 видео |
| **Свежесть** | дата последней загрузки | ≤ 90 дней (иначе канал мёртв) |
| **Случайность упоминания** | доля видео с seed-словами в заголовках | 1–20 % (не 0 и не 50) |
| **Разбросанность тем** | энтропия тем по заголовкам | высокая = «не решил, о чём говорить» |

Последний сигнал — ключевой для вашей задачи: у такого автора нет темы, значит **тема ещё назначаема**. У «Канта Говорит» (58 видео, 4 упоминания) тема уже есть — переубеждать сложнее.

## 3. Стратегия запросов

### 3.1. Редкие слова = высокая точность
Чем реже слово, тем меньше мусора. Порядок по убыванию точности:

```
крионика
иммортализм
трансгуманизм
загрузка сознания
цифровое бессмертие
квантовое бессмертие
продление жизни
наномедицина
```

### 3.2. Массовые слова = широкий охват, но нужен фильтр
```
бессмертие
вечная жизнь
страх смерти
смысл жизни
что после смерти
смерть неизбежна
```

### 3.3. Комбо «чужая тема + наше слово» — самый ценный приём
Именно так ловятся «проговорившиеся»: человек снимал про другое, а слово проскочило.

```
бессмертие продуктивность
бессмертие бизнес
бессмертие психология
бессмертие здоровье
бессмертие медитация
бессмертие наука
бессмертие ИИ
бессмертие христианство
бессмертие смысл
```

### 3.4. Чего НЕ делать
- Не искать `иммортализм` в одиночку — вернёт только «профессионалов» (Данила Медведев и т.п.), это не ваша аудитория.
- Не сортировать по релевантности — сортируйте по дате (свежие = живые каналы).
- Не брать топ-результаты: там старые популярные видео, а не новички.

## 4. Платформы

### YouTube
- Поиск: `https://www.youtube.com/results?search_query=<q>` + пагинация через `youtubei/v1/search` (в скрипте реализовано, 3 страницы на запрос).
- Размер канала: `/channel/<id>/about` → `subscriberCountText`, `videoCountText`.
- Скан канала: `/channel/<id>/videos` + пагинация → все заголовки → доля seed-слов.
- **Ограничение:** субтитры сейчас закрыты `po_token` (проверено: `timedtext` отдаёт 0 байт, `get_transcript` — 400). Поэтому поиск по субтитрам работает только через сам поиск YouTube, а не через скачивание транскриптов.

### Rutube
- Поиск: `https://rutube.ru/api/search/video/?query=<q>&limit=30` — открытый JSON, без токена.
- Поля: `title`, `description`, `author{id,name}`, `created_ts` (ISO-строка!), `hits`.
- Размер канала: `https://rutube.ru/api/video/person/<id>/` → `num_pages * per_page` = число видео (подписчиков API не отдаёт).
- Плюс: аудитория менее «выжжена», конкуренция за внимание ниже.

### VK Video
- API-метод `video.search`: `https://api.vk.com/method/video.search?q=<q>&count=200&sort=2&access_token=<token>&v=5.199` (`sort=2` = по дате). Нужен токен (создать приложение → сервисный или implicit-flow токен).
- Веб-поиск `https://vk.com/video?q=<q>&section=search` требует авторизации, парсинг без токена нестабилен.
- Полезно: `groups.search` для поиска сообществ по теме, затем `video.get` по `owner_id`.

## 5. Инструмент

Основной инструмент — F#-проект [`src/Scraping`](src/Scraping/README.md) (.NET 10, без NuGet-зависимостей).

```bash
# оба источника, дефолтный набор запросов
dotnet run --project src/Scraping/Scraping.fsproj -- find-bloggers

# точный набор запросов, только YouTube, скан 10 каналов
dotnet run --project src/Scraping/Scraping.fsproj -- find-bloggers \
  --queries "крионика,квантовое бессмертие,загрузка сознания,бессмертие наука" \
  --source yt --scan 10

# только Rutube, без скана каналов (быстро)
dotnet run --project src/Scraping/Scraping.fsproj -- find-bloggers --source rutube --no-scan
```

Параметры: `--max-subs` (5000), `--max-videos` (120), `--max-days` (400), `--max-per-query` (30), `--scan` (12).

Другие команды: `channel-videos`, `shorts`, `playlist`, `thumbs`, `verify` — см. [`src/Scraping/README.md`](src/Scraping/README.md).

Выход: таблица с колонкой `Profile`:
- `TARGET (mentioned in passing)` — ваш профиль;
- `dedicated (too on-topic)` — уже сделал тему своей, не новичок по теме;
- `no seed hits` — упоминание было только в описании/субтитрах, в заголовках нет.

Результат пишется в два файла:

- `yt_blogger_candidates.tsv` — по строке на канал (`--out`);
- `yt_blogger_videos.tsv` — **по строке на найденное видео, с прямой ссылкой** (`--videos-out`).

Таблица видео с URL печатается и в консоль в конце прогона — ссылки можно копировать прямо из терминала.

## 6. Что делать после того, как нашли (и что вас забанят)

### Работает
1. **Комментировать в первые 24 часа** — автор читает всё, алгоритм ещё разгоняет видео.
2. **Задавать вопрос, а не давать ссылку.** «Ты сказал про бессмертие — а рассматривал вариант, что это проблема тела, а не души?» Вопрос втягивает в диалог, ссылка — нет.
3. **Отвечать на ответ.** Один развёрнутый диалог даёт больше, чем 50 однострочных комментариев.
4. **Предлагать тему, а не идеологию.** У него нет темы — это ваш рычаг: «сними разбор, почему квантовое бессмертие — не метафора». Конкретное ТЗ + хук + 3 тезиса.
5. **Давать материал:** ссылку на исследование, цифры, цитату. Автору без темы нужен контент, а не лозунг.
6. **Хвалить точку, где он был прав** — потом спорить с одной. Это снижает защиту.

### Забанит / убьёт охват
- Одинаковые комментарии подряд (спам-фильтр YouTube).
- Ссылки в первых комментариях — режутся и понижаются.
- Массовые аккаунты для «engagement» — нарушение ToS, вычисляется по паттернам, канал-получатель тоже страдает.
- Спор с переходом на личности в первом же комментарии — автор закрывается навсегда.
- Комментировать «не те» видео (где бессмертие не упоминалось) — выглядит как бот.

### Метрика, которую стоит вести
`канал → видео-триггер → комментарий → ответил? → снял видео на тему?`
Цель — не лайки, а **второе видео автора на вашу тему**. Это и есть «перенаправление».

## 7. Ограничения, о которых честно

- **Поиск по субтитрам — не 100 %.** YouTube индексирует не всё и не мгновенно; свежее видео (первые часы) может не находиться по слову из речи.
- **`hitRatio` считается по заголовкам**, а не по речи. Канал может быть «про бессмертие» по сути, но с нейтральными заголовками — тогда он ошибочно попадёт в `TARGET`. Проверяйте вручную 2–3 видео.
- **Rutube-выборка шумная**: много аниме-перезаливов («Путешествие к бессмертию») и дорам. Фильтруйте по `description` и по числу видео.
- **VK** без токена не парсится — нужен токен, это 5 минут в настройках приложения.
